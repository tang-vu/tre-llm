# Code of Conduct

Dự án theo [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) (tinh thần):

- Tôn trọng, không công kích cá nhân, không phân biệt.
- Phản hồi mang tính xây dựng; ghi nhận giới hạn kỹ thuật một cách trung thực.
- Báo cáo hành vi vi phạm qua GitHub issue (private contact: mở issue security).

Vi phạm có thể dẫn đến cảnh báo hoặc hạn chế tương tác, tuỳ mức độ.
