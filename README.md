# TreLLM

**LLM tiếng Việt, vừa sức máy bạn.** — Vietnamese AI that fits your machine.

TreLLM helps you run verified local language models in Vietnamese on the hardware you actually have — from modest CPU laptops to GPU workstations — with honest evidence about what works.

See `STATUS.md` for current development state and `docs/` for architecture and research notes.
